# Adopt libvaxis’s low-level API for fiew v0.1

## Context

fiew v0.1 is a Zig 0.16.0 terminal application targeting Ghostty on Apple Silicon macOS. It needs terminal capability detection, input decoding, mouse support, and cell-based rendering without selecting a widget framework before its interaction model is defined.

## Decision

Use libvaxis’s low-level API, pinned through Zig’s package manager to immutable revision `c060d314930c5552b99a89278a6a695baf0352da`. Do not use libvaxis’s higher-level `vxfw` framework. Commit the dependency hash generated in `build.zig.zon`.

## Rationale

At the inspected revision, libvaxis declares Zig 0.16.0 support, detects VT features with terminal queries rather than terminfo, and exposes a low-level API that lets fiew own its event loop and rendering model. The current tagged libvaxis release, v0.5.1, declares Zig 0.13.0 support and is therefore incompatible with the selected toolchain.

## Consequences

The dependency revision must remain immutable and upgrades require deliberate Zig 0.16 compatibility verification. fiew owns its event loop, layout, focus, input mapping, and rendering rather than delegating them to `vxfw`. Revisit the pin when libvaxis publishes a Zig-0.16-compatible tagged release.
