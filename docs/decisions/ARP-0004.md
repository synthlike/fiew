# Render a Mermaid subset as terminal text

## Context

fiew v0.1 should preview useful Mermaid diagrams while remaining a text-first terminal viewer. Full Mermaid rendering requires a browser-oriented renderer before Kitty graphics can display an image, adding substantial dependencies and opaque raster output. The alternatives and compatibility facts are recorded in [Mermaid ASCII rendering constraints for fiew v0.1](<docs/research/mermaid-ascii-rendering-constraints-for-fiew-v0-1.md>). Observable scope is owned by [Decide Mermaid rendering scope and approach](<.project/issues/ISSUE-0011-decide-mermaid-rendering-scope-and-approach.md>).

## Decision

Use an optional user-installed `mermaid-ascii` 1.5.x executable from `PATH` to render a defined Mermaid subset as terminal text. Support only fenced code blocks labeled `mermaid` in Markdown and only flowchart, sequence, and entity-relationship diagram types. Use Unicode box drawing by default and expose strict ASCII as an alternate command.

Invoke the executable directly without a shell, pass source only through stdin, and render only sanitized captured output through fiew's normal cell renderer. Use compact fixed spacing and horizontal scrolling rather than image output or width-dependent rerendering. Do not use Mermaid CLI, Node, Chromium, SVG, PNG, or Kitty graphics in v0.1.

## Rationale

Terminal text remains selectable, navigable, copyable, theme-compatible, and independent of image-placement state. The external binary has a small integration surface, publishes an Apple Silicon build, and avoids adding another implementation language or browser runtime to fiew. Explicit subset labeling and source-preserving fallback avoid overstating compatibility with official Mermaid.

## Consequences

- Users install and update `mermaid-ascii` independently. fiew requires the 1.5 minor line and does not bundle or download it.
- Rendering is optional. Missing, incompatible, slow, failed, oversized, or unsupported rendering never hides the Markdown source.
- fiew must bound subprocess input, output, stderr, and runtime and sanitize all output before cell rendering.
- Diagram layout may exceed the viewport and requires horizontal scrolling; terminal resize preserves scroll rather than promising responsive reflow.
- Full Mermaid language coverage, standalone Mermaid files, automatic rendering, SVG/PNG, Kitty graphics, hyperlinks, interactivity, and rich diagram navigation are deferred.
