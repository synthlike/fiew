# fiew v0.2 portable terminal smoke test

Use this checklist for terminal behavior that deterministic tests cannot verify. Run it in Ghostty, Kitty, and WezTerm on Apple Silicon macOS and the supported x86_64 Linux environment. Record the terminal version, operating system, fiew revision, and unavailable optional tools with each result.

## Setup

1. Build fiew from the locked source with `zig build`.
2. Open a repository containing Zig, Markdown, a supported Mermaid fence, Git changes, review threads, and bookmarks.
3. Run fiew directly in the terminal. Do not run it through a multiplexer.

## Core behavior

1. Confirm startup, alternate-screen entry, resize, indexed color, Unicode text, Project browsing, Review Diff, Review Threads, bookmarks, and both file finders.
2. Complete the core workflow using only the keyboard. Confirm `Tab`, `Shift-Tab`, arrows, modal bindings, command menus, `Enter`, `Esc`, `Ctrl-o`, `Ctrl-i`, `Ctrl-c`, and `Space q` work.
3. Confirm mouse selection works when the terminal reports it. Disable terminal mouse reporting when possible and confirm every workflow remains keyboard-complete.
4. Set `NO_COLOR=1`, restart fiew, and confirm labels, markers, reverse selection, bold, dimming, and text remain readable without color.
5. If the terminal can disable synchronized updates, disable them and confirm drawing remains correct apart from possible visible incremental updates.
6. Resize below the supported dimensions and confirm the unsupported-size view appears. Resize back and confirm the prior workspace remains usable.

## Restoration and shutdown

1. Quit with `Space q`. Confirm the previous screen returns, the cursor is visible, and normal line input and echo work.
2. Restart, send `SIGINT` from another shell with `kill -INT <pid>`, and repeat the restoration checks.
3. Restart, send `SIGTERM` with `kill -TERM <pid>`, and repeat the restoration checks.
4. Trigger a Git refresh, then immediately quit or send a handled signal. Confirm fiew exits promptly and leaves no `git` child process.

## Optional integrations

1. With optional tools absent, confirm Markdown and plain-text viewing remain usable and exact unavailable states do not alter selection or history.
2. When installed, exercise Mermaid preview and trusted ZLS definition, reference, and hover behavior. Cancel each operation and confirm no child remains after quit.
3. Repeat shutdown while an optional child is active and confirm it is terminated and reaped.

## Audit

1. Confirm fiew did not invoke a shell, clipboard helper, OSC 52, filesystem watcher, graphics protocol, or terminal-name-specific path.
2. Confirm source and Git content did not change.
3. Save pass/fail evidence separately for each terminal and operating-system target. Do not convert an unavailable optional-tool result into a successful integration result.
