# fiew v0.1 release checklist

Use this checklist from a clean checkout on Apple Silicon macOS. The v0.1 release is a manually published, unsigned and unnotarized Ghostty binary. Signing, notarization, package managers, and automatic publication are not release gates.

## Build and verify

1. Confirm the checkout is clean with `git status --short`.
2. Confirm `uname -m` reports `arm64`, `zig version` reports `0.16.0`, and Git and Ghostty are installed.
3. Run the deterministic and integration suites:

   ```sh
   zig build test --summary all
   zig build test -Dgit-integration --summary all
   ```

4. Produce the archive and checksum:

   ```sh
   python3 tools/package-release.py --version 0.1.0
   ```

5. Confirm a second run from the same commit produces the same checksum:

   ```sh
   cp dist/fiew-v0.1.0-darwin-arm64.tar.gz.sha256 /tmp/fiew-first.sha256
   python3 tools/package-release.py --version 0.1.0
   diff -u /tmp/fiew-first.sha256 dist/fiew-v0.1.0-darwin-arm64.tar.gz.sha256
   ```

6. Inspect the archive and executable:

   ```sh
   (cd dist && shasum -a 256 -c fiew-v0.1.0-darwin-arm64.tar.gz.sha256)
   tar -tzf dist/fiew-v0.1.0-darwin-arm64.tar.gz
   rm -rf /tmp/fiew-v0.1.0-smoke
   mkdir /tmp/fiew-v0.1.0-smoke
   tar -xzf dist/fiew-v0.1.0-darwin-arm64.tar.gz -C /tmp/fiew-v0.1.0-smoke
   file /tmp/fiew-v0.1.0-smoke/fiew
   /tmp/fiew-v0.1.0-smoke/fiew --version
   otool -L /tmp/fiew-v0.1.0-smoke/fiew
   ```

   Require one executable named `fiew`, Mach-O ARM64 architecture, version `0.1.0`, and the pinned dependency revisions recorded by `--version`.

7. Run the extracted executable in Ghostty against the verified smoke repository. Confirm startup, Project and Review Diff rendering, and terminal restoration on normal quit and `Ctrl-C`.

## Publish manually

1. Create the Git tag `v0.1.0` only after the release commit and checklist results are reviewed.
2. Create a GitHub Release for that tag manually.
3. Upload both files without renaming them:
   - `fiew-v0.1.0-darwin-arm64.tar.gz`
   - `fiew-v0.1.0-darwin-arm64.tar.gz.sha256`
4. Copy the supported platform, Git prerequisite, installation commands, checksum verification, and unsigned/unnotarized status from `README.md` into the release notes.
5. Do not claim Linux, Intel macOS, non-Ghostty terminals, Markdown structure, Mermaid, fuzzy finding, ZLS, signing, notarization, package-manager installation, or automatic updates.
