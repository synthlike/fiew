# Domain model template

```md
# <Context name>

<One or two sentences describing the context and why it exists.>

## Language

**Order**:
A customer request for the defined outcome.
_Avoid_: Transaction, job

**Customer**:
A person or organization that places orders.
_Avoid_: Client, account
```

Definitions should say what a concept is in one or two sentences. Choose a canonical term and list discouraged synonyms under `_Avoid_`. Include only terms specific to the project's domain.
