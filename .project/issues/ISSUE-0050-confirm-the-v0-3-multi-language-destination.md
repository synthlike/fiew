# Confirm the v0.3 multi-language destination

## Question

Which language ecosystems and standing capability boundaries define v0.3?

## Answer

v0.3 requires Go with optional trusted `gopls` and the JavaScript/JSX/TypeScript/TSX React-capable family with optional trusted language tooling. It introduces a shared fiew-owned read-only capability boundary, language-aware diffs, and semantic anchors where reliable. Tree-sitter or plain text remains available without a server. Workspace symbols, diagnostics, module navigation, test navigation, and file-move reanchoring are candidates whose release priority remains to be decided.
